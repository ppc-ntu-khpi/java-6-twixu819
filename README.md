# Практична робота "Поглиблене використання масивів"
Цей репозиторій містить iнструкції та стартовий код для виконання практичної роботи з теми.

---

## Обране завдання
Завдання №5: Обчислити суму елементів матриці розміром ```N``` X ```M```.

---

## Опис розв'язання
Логіка реалізована в класі ```MatrixProcessor``` за допомогою ```Arrays.stream``` без використання класичних циклів, що забезпечує чистоту коду. Тестовий клас ```Main``` використовується лише для запуску та демонстрації результату. Програма відповідає стандартам іменування та оптимізації типів даних. Програма оптимізована за пам'яттю та не містить зайвих інтерфейсів користувача в основному класі.

---

## Як запустити програму 
Щоб запустити програму, треба в терміналі ввести ось цю команду: ```java -cp src Main```
